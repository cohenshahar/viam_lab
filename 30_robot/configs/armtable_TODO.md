# Arm-table (real): what is ready and what is still unknown

Draft config: `armtable_DRAFT.json` (generated by `20_sim/tools/make_configs.py`). Same part names as the sim
machine `armtable-sim` (`kr6`, `vacuum`, `cam-wrist`, the rig obstacles), so the same scripts and `cap` verbs run on both.

## Ready
- KR6 kinematics = the rig's KR6 (checked: 0.0000 mm, 50 poses, `build_arena_files.py`).
- Arm mount and every rig obstacle (table, fence, cage posts, +30 mm margin) from the thesis rig model.
- The arena demo and the collision audit, proven in sim (`20_sim/scripts/arena_demo.py`).

## Unknown (to settle on the arm-table, Sunday / next week)
| Item | Why it matters | How to find out |
|---|---|---|
| KR6 in the Viam KUKA module | `viam-soleng:viam-kuka` is confirmed only for the KR10 R900-2; it picks its URDF by `model`. A KR6 needs a URDF added to the module (fork) | read the module source; our KR6 kinematics can be turned into a URDF |
| Module build | its registry build is `linux/arm64` only; the arm-table computer is probably x86 | check `uname -m` on that computer; build the module from source if x86 |
| Controller connection | IP, port, and the KRL program the module talks to (TCP) on the KUKA controller | the controller's network settings; the module README / source |
| Vacuum hardware | how the suction is switched (valve on a GPIO / relay?) and how "holding" is sensed (vacuum switch?) | look at the rig's pneumatics; then a Viam board + our gripper model for the real valve |
| Where the box is | the sim knows it exactly; the real robot does not | first: a fixed spot (fixture or tape mark); later: camera + vision service |
| Arm base pose | the rig model says (-450, -600, 750) mm; the real mount may differ | tape-measure from two table edges |
| Safety | slow speed, joint limits, hardware E-stop within reach | `joint_speed` low (5) on day one; second person at the E-stop |
| `cap` on the real machine | `cap` checks the cup against the sim's box; on hardware the vacuum switch must decide | add a "real" mode to `cap` (use the gripper's holding signal, no sim box check) |
